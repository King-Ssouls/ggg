# Практическая работа 7–8

Новый проект на C# для получения и сохранения положения Международной космической станции. В основной части есть внешний API, фоновое обновление, Polly, журналирование и проверки состояния. Дополнительно сделаны GeoJSON-карта и настройки Prometheus/Grafana.
