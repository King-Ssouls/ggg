# Практическая работа 5

Учебный проект на C# и ASP.NET Core Web API для варианта 1 — тикет-система поддержки. В проекте есть регистрация, вход по JWT, refresh-токены, роли User/Agent/Admin и заявки, доступ к которым проверяется по владельцу и правам.

## Материалы

- [Инструкция по запуску и проверке](ИНСТРУКЦИЯ_ПО_ЗАПУСКУ.md)
- [Вопросы и ответы для защиты](ВОПРОСЫ_К_ЗАЩИТЕ.md)

Код проекта находится в этой папке. Секрет JWT задаётся через User Secrets. SQLite база и таблицы создаются при первом запуске.
