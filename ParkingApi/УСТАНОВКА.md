# Установка и запуск ParkingApi

## Требования

- .NET 10 SDK.
- Доступ к NuGet для первого восстановления пакетов.
- SQLite отдельно не устанавливается: база хранится в `parking.db`.

## Через Visual Studio

Откройте `ParkingApi.csproj`, дождитесь восстановления NuGet-пакетов и запустите профиль `ParkingApi`. Swagger доступен на `https://localhost:7047/swagger`.

## Через PowerShell

Откройте терминал в папке `ParkingApi`:

```powershell
dotnet --version
dotnet restore
dotnet tool restore
dotnet ef migrations list
dotnet ef database update
dotnet run
```

Команда `dotnet tool restore` устанавливает локальный `dotnet-ef` версии 10.0.12 из `.config/dotnet-tools.json`. У проекта ConcertTicketsApi своя версия инструмента, поэтому версии не конфликтуют. Версия инструмента и версии EF Core в проекте согласованы. При старте приложение тоже применяет миграции. Первый запуск может запросить доверие HTTPS-сертификату; для этого выполните `dotnet dev-certs https --trust`.

Чтобы сбросить локальные данные, остановите приложение и удалите `parking.db`. Следующий запуск создаст базу миграциями.
